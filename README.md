# Kinetyka

Kamerka internetowa jako kontroler ruchowy: cząsteczki, dźwięk i gry sterowane ruchem ciała lub dłoni.
Jeden plik (`index.html`), działa w Chrome/Edge bez instalacji. Obraz z kamery jest przetwarzany lokalnie w przeglądarce i nigdzie nie jest wysyłany.

Tryby: Rozrzut, Podążaj, Strefy, Pędzel, Sylwetka, Bańki, Piasek, Perkusja, Wstęga, Życie, Pong, Świetliki.
Opcje: śledzenie dłoni i samego palca (MediaPipe, model ładowany z internetu), mikrofon, nagrywanie, kiosk, tryb dwóch osób.

Klawisze: `1`–`9` `0` `-` `=` tryby, `H` panel, `F` pełny ekran, `C` kalibracja tła, `Spacja` pauza, `P` zdjęcie.
